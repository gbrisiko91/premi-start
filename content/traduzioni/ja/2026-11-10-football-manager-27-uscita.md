**Football Manager 27**が本日11月10日、全世界で発売された。**Sports Interactive**と**SEGA**による最新作のサッカー経営シミュレーションは、PC、**PS5**と**Xbox Series X|S**、そして**Netflix**経由のスマートフォン向けに同時リリースされ、発売初日から**Xbox Game Pass**にも対応している。イギリスのスタジオにとっては、ファンの賛否が分かれた前作の印象を払拭しなければならない、重要なリリースとなる。

## Football Manager 27をプレイできる環境：PC、コンソール、モバイル

Sports Interactiveが[Football Managerの公式サイト](https://www.footballmanager.com/node/1106)で発表したとおり、本日から利用できるバージョンは次の3つだ。

- PCおよびMac向けの**Football Manager 27**。Steam、Epic Games Store、Microsoft Storeで販売され、Game Pass対応のPC版Xboxアプリでもプレイできる。
- PS5およびXbox Series X|S向けの**Football Manager 27 Console**。
- iOSおよびAndroid向けの**Football Manager 27 Mobile**。Netflixのサブスクリプションに含まれる。

PC版のイタリアでの希望小売価格は59.99ユーロ。Game Pass加入者は追加料金なしでダウンロードできる。

## FM26からのFootball Manager 27の新要素

新作の中心となるのは**インターフェース**だ。これは、FM25の開発中止を経て新エンジンで初めて作られたFM26で、最も批判を浴びた部分だった。Sports Interactiveは、クリック数の削減、上部メニューによる素早いナビゲーション、すっきりとしたフルスクリーン画面に加え、ショートカット、ブックマーク、カスタマイズ可能なパネルを約束している。

コミュニティから要望の多かった機能もいくつか復活する。

- リアルタイムで見守る**カップ戦の抽選**
- 土壇場の交渉が繰り広げられる**移籍市場最終日**
- 刷新された**ニュースフィード**と、ヒートマップやパスマップを含む充実したスタッツ

さらにMultiplayer.itのレビューによれば、FIFAeと共同開発した新モード**Shuffle Draft**も搭載されている。2人から32人で参加できるドラフト形式のトーナメントのようなもので、短時間で遊べる試合を想定している。

## Football Manager 27のレビュー：デビューの評価は

初期の評価は好意的だ。発売時点のMetacriticでは、少数のレビューながらすべて好評で、平均スコアは**82**となっている。Multiplayer.itは7.5点をつけた。ペナルティエリアへの飛び出しをより細かく指示できる新しい戦術システムは高く評価された一方、試合エンジンでは依然としてディフェンダーの反応が鈍く、インターフェースも改善されたとはいえ日常的な操作ではまだ動作が遅いと指摘している。

浮かび上がるのは、FM26からは明確に前進したものの、多くのファンが最後の傑作と考えるFM24の水準にはまだ届いていない、という評価だ。Steamで多くの批判を集めた前作の後だけに、発売後数週間のプレイヤーの反応が鍵となるだろう。ここ数日、[ALL.Netサービスへのハッカー攻撃](/articoli/sega-all-net-attacco-hacker/)でも話題になったSEGAにとって、今回は重要なローンチとなる。

### Football Manager 27はPS5で発売される？

はい。Football Manager 27 Consoleは11月10日からPS5およびXbox Series X|Sで発売されている。
